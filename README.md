# AgroBoard : téléchargements

Tableau de bord du groupe : dépenses et recettes, cotisations, parcelles et sol, campagnes et rentabilité.

**[Télécharger la dernière version](https://github.com/Rockstudio352/agroboard-telechargements/releases/latest)**, puis choisis le fichier qui correspond à ton appareil :

| Fichier | Pour qui | Appareil |
|---------|----------|----------|
| `AgroBoard-x.y.z.apk` | tous les membres | téléphone Android |
| `AgroBoard-Setup-x.y.z.exe` | tous les membres | ordinateur Windows |
| `AgroBoard-Admin-x.y.z.apk` | administrateur et responsables | téléphone Android |
| `AgroBoard-Admin-Setup-x.y.z.exe` | administrateur et responsables | ordinateur Windows |

## Installer

- **Téléphone :** ouvre le fichier `.apk` téléchargé. Si Android demande l'autorisation d'installer des applications inconnues, accepte-la pour ton navigateur.
- **Ordinateur :** lance le fichier `.exe`. Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires** puis **Exécuter quand même**.

Crée ensuite ton compte (prénom, e-mail, mot de passe). Tu ne verras les données du groupe qu'une fois ton compte validé par l'administrateur.

## Mises à jour

- **Ordinateur :** automatique. La nouvelle version se télécharge seule et s'installe à la fermeture de l'application.
- **Téléphone :** un bandeau « Nouvelle version disponible » apparaît dans l'application. Touche **Télécharger**, puis ouvre le fichier. Tes données sont conservées.
